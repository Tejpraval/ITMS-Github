Indigenous Contactless Integrated Track Monitoring System

A computer-vision prototype for automated railway fastener detection, defect classification, and track inspection recording using YOLO26n and the RFDD dataset.

Project Overview

This project demonstrates a software-based railway track inspection pipeline inspired by the concept of Integrated Track Monitoring Systems (ITMS). Railway track images are processed using a deep-learning object detection model to identify fasteners and classify their condition.

This is an experimental computer-vision prototype and is not intended to replace engineering-grade railway inspection systems.

RFDD Dataset

The Railway Fastener Defect Dataset (RFDD) contains railway fastener images covering six condition classes.


  • Deformed
  • Fractured
  • Missing
  • Inverted
  • Normal
  • Displaced

Limitations & Future Scope

  • Prototype uses image/video-based computer vision.
  • It does not perform complete railway track geometry measurement.
  • It does not replace certified railway inspection equipment.
  • Future work can integrate real-time camera systems and additional sensors.
  • Further optimization can improve real-time deployment performance.
